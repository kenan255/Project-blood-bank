Blood Bank Management System

1.	Project Title

Blood Bank Management System Using Python

2.	Project Description

The purpose of this project is to create a simple Blood Bank Management System using Python. The program collects information from potential blood donors and checks whether they meet the basic donation requirements, such as age and health condition. It also collects the donor's blood type.

3.	Methods and Techniques Used

The project uses the following Python concepts and functions:

1.	print(): Displays welcome messages and instructions to the user.
2.	input(): Collects information from the user, such as name, age, health condition, and blood type.
3.	if and else statements: Check the donor's eligibility based on the required conditions.
4.	Variables: Store the information entered by the donor.
5.	Comparison Operators: Check whether the donor is 18 years old or older.
6.	Logical Operations: Help the program make decisions based on the user's answers.
